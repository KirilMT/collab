## 📋 DOCUMENT PURPOSE

This document tracks all identified bugs in the Collab Runtime package. Each bug includes:

- **Description**: What the bug is and how it manifests
- **Priority**: Critical, High, Medium, or Low
- **Status**: Open, In Progress, or Fixed
- **Affected Files**: Files that need modification

> [!NOTE]
> **Document Relationship:** This document tracks bugs in existing functionality. For new features and strategic improvements, see `collab_roadmap.md`.

### Document Quality Rules

| Rule                        | Action                                                                |
| --------------------------- | --------------------------------------------------------------------- |
| **Update Summary Counts**   | After EVERY status change, update the Summary table                   |
| **Avoid Duplicates**        | ALWAYS search document before adding new bug                          |
| **Keep Open Bugs Detailed** | Open bugs MUST have: Description, Current/Expected, Possible Solution |
| **Target: ~300 Lines Max**  | Archive resolved bugs (30+ days) to keep document efficient           |
